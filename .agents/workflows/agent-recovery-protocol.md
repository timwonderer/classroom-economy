---
description: Follow this protocol if agent is not making meaningful progress after 3 rounds on the same problem.
---

When an implementation agent makes three or more low-value iterations without meaningful progress:

1. Pause.
2. State objective.
3. State assumptions.
4. State authority.
5. State workflow.
6. State what worked.
7. State what failed.
8. If starting today, would you choose the same workflow?
9. Propose a new workflow based on evidence.
