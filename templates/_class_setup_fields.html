{# Shared class-creation fields — presentation only. Genuinely common to BOTH surfaces that create a class: - first-class onboarding (admin_signup_class.html) - authenticated add-class (admin_create_class.html) Owns ONLY the class-identity inputs (class name + section). It deliberately does NOT own the
tag, CSRF token, form action, teacher name capture, ToS/Turnstile, submit/cancel buttons, navigation, or any terminal behavior — each parent surface owns those context-specific concerns and their distinct authority/security requirements. #}
{# "Your display name" is ONE label over TWO boxes. The backend needs a first and last name, but the two-box framing under a single friendly label lets a teacher enter whatever they want (Mr. Jones, Sam Jones, Chief Jones, Sam theMan). Per-box labels are visually-hidden so both inputs sit on one shared baseline. #}
