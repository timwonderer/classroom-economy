How to: Payroll Management

Run payroll, adjust pay rates, and review payouts by class.

Use Run Payroll Now to issue payouts immediately based on attendance since the last run.

Example: If your last run was Friday, a Monday run will pay students for Monday attendance only.

Reminder: This action creates transactions for all eligible students.

Set pay rates, schedules, and payroll rules in the Settings tab.

Note: Student "Projected Pay" visible on dashboards automatically aligns with these rules (e.g. if you set a $500 max, their projection will reflect that cap).

Use the preview tables on the Overview tab to confirm your next run totals before enabling auto-run.

settingsBasic Settings:

  • Pay rate: How much students earn per time unit
    • Per hour: Simpler math (e.g., $10/hour)
    • Per minute: More granular for short class periods (e.g., $0.17/minute = about $10/hour)
  • Rate guidance: For a 50-minute class, $0.20/minute equals $10 per class period.
  • Expected weekly hours: Drives your Classroom Wage Index (CWI)
    • Example: $10/hour × 5 hours/week = $50 weekly CWI
    • Use this to balance rent, insurance, and store prices

calendar_view_weekSchedule Settings:

  • Pay schedule: When payroll runs automatically
    • Weekly: Consistent income, easier budgeting for students
    • Bi-weekly: Mirrors real paychecks, requires more planning
    • Monthly: Advanced students only, teaches long-term budgeting
  • Auto run: When enabled, payroll runs on schedule without you clicking "Run Payroll"
  • Schedule example: Weekly on Fridays, or bi-weekly every other Friday.

tuneAdvanced Settings:

  • Attendance rules: Choose which tap types count (Start Work, Break, Done)
warningSide effects: Rate or schedule changes only affect future payroll runs. Past payments remain unchanged.
lightbulbRecommended Start: $10/hour, weekly schedule, 5 expected hours/week. This creates a $50 weekly CWI that is easy for students to work with.

Add bonuses or fines for specific behaviors in the Rewards & Fines tab.

Use the Manual tab to issue one-time payments or adjustments.

Review past payroll runs and totals in the History tab.
