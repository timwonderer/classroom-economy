# Class Setup and Join Codes

## Overview

Each class you teach is its own economy. Balances, payroll settings, store items, rent, and attendance all belong to one class and never cross into another. If you teach four periods, you create four classes, each with its own join code.

You create your first class when you sign up. After that you add classes from the sidebar.

## Step-by-step instructions

### Creating a class

1. In the teacher sidebar, select **Create New Class**.
2. Fill in the form:

   | Field | What to enter |
   | --- | --- |
   | Class Name | What you call the course — "Chemistry", "Math Period 3" |
   | Section | Optional, and private — see the warning below before relying on it |
   | Time Zone | The time zone the class actually meets in |
   | Your display name | Two boxes, one name. Whatever your students should see — "Ms." and "Ayala", or "Chief" and "Jones" |

3. Select **Create class**.

You land in the new class immediately, and the sidebar switches to it.

### Sharing the join code

Every class gets its own join code automatically.

1. In the teacher sidebar, open **Classroom**.
2. Select **Students**.
3. On the **Class Roster** tab, the join code is in the green card at the top. Select **Copy** to put it on your clipboard.

The card also shows whether every seat has been claimed, and a short set of instructions to read aloud to students:

1. Go to the student sign-in page.
2. Select **First Time? Set Up Account**.
3. Enter the join code, then the first and last name from your roster.

### Adding students to the roster

The join code alone does not let a student in — their name has to be on the roster first.

1. On the **Students** page, select the **Add Students** tab.
2. Paste from Excel or Google Sheets, or type into the grid. Two columns (First Name, Last Name) or three (First Name, Last Name, Notes) are accepted.
3. Select **Add Students**.

Each row becomes an unclaimed seat. When a student enters the join code and their name, they take that seat.

### Switching between classes

**Switch Class** is at the bottom of the teacher sidebar, above **Create New Class**. Pick a class and the page reloads into it. Every page you open afterward — payroll, store, attendance, banking — applies to the class you selected.

The choice sticks. It is saved to your account, not to the browser tab, so closing the app and signing back in later — on any device — puts you back in the class you were last working in. Creating a class also switches you into it.

If the switch fails, a yellow warning appears directly beneath the dropdown reading *Unable to switch classes right now* or *Network error while switching classes*, and you stay where you are. Nothing is half-applied; try again.

### The "Select Your Class" screen

Occasionally you sign in and get a page headed **Select Your Class** instead of your dashboard, explaining that your last active class could not be located.

This is a fallback, not an error. Choose a class from the dropdown — each is listed as its name followed by its join code — and select **Continue to Dashboard**. Nothing in any class economy is affected. There is also a **Create another class** link if you landed here because you have no class yet.

### Renaming a class

**Class Name** and **Section** can both be changed later on **Settings > Customizations**. The time zone cannot — see below.

## Important notes

> [!WARNING]
> **The time zone is permanent.** It anchors when a payroll day starts, when rent comes due, and how attendance days are counted. You cannot change it after the class is created. If you pick the wrong one, create a new class.

> [!WARNING]
> **Section is never displayed anywhere.** It saves, and you can edit it later, but it does not appear in the Switch Class dropdown, on the Select Your Class screen, on your dashboard, or to students. The switcher lists each class by its **Class Name** alone. If you teach two sections of the same course, put the distinction in the class name — "Chemistry P1", "Chemistry P3" — or you will not be able to tell them apart when switching.

> [!IMPORTANT]
> **Names must match.** A student claiming a seat types the first and last name exactly as they appear on your roster. If a student cannot find their account, check the roster spelling before anything else.

> [!NOTE]
> Two students with the same name are fine. Each one gets a separate seat and a unique code for claiming it.

> [!NOTE]
> Your display name is set per class. Changing it in one class does not change it in another.
