# Customizations

## Overview

**Customizations** controls the cosmetic layer of one class: what students call you, what the class is called, and whether the getting-started widget is showing. It also displays the ID numbers you will be asked for if you file a support ticket.

Nothing on this page changes how the economy behaves.

## Step-by-step instructions

### Opening the page

1. In the teacher sidebar, open **Class Tools**.
2. Select **Customizations**.

### Setting your display name

Under **Teacher Display Name** there are two boxes — **Display Name First Half** and **Display Name Second Half**. They are joined together and shown to students as one name. You can put anything in them:

| First half | Second half | Students see |
| --- | --- | --- |
| Ms. | Ayala | Ms. Ayala |
| Chief | | Chief |
| Mr. | R. | Mr. R. |

Below the boxes, **Currently displaying as:** shows the name in force right now.

### Naming the class

Under **Class Display Settings**:

| Field | What to enter |
| --- | --- |
| Class Display Name | What you call the course — "Honors Bio", "AP Calc" |
| Section | How you tell periods apart — "Period 1", "Block A" |

If no class is selected you see a note telling you to switch to a class first.

### Saving

Select **Save Settings** at the bottom. Both the teacher name and the class names save together.

### Finding your support IDs

The **Account Information** panel lists:

- **Teacher ID** — how you are identified on a support ticket
- **Account Created** — the date you signed up
- **Class ID** — how this class is identified on a support ticket

Quote these instead of student names when you contact support.

### Bringing back the getting-started widget

If you dismissed the setup checklist on your dashboard and want it back, select **Show Getting Started Widget** at the bottom of the page.

## Important notes

> [!IMPORTANT]
> **Your display name is set per class.** Each class economy is independent, so changing your name here does not change it in your other periods. Set it in each class you want it in.

> [!NOTE]
> These settings are cosmetic. Renaming a class does not affect its join code, its balances, or any of its economy settings.

> [!NOTE]
> Renaming a class changes what students see on their dashboard the next time they load it.

> [!TIP]
> Use **Section** consistently across all your classes — "Period 1", "Period 2", and so on. It is what the class switcher uses to keep your periods apart.
