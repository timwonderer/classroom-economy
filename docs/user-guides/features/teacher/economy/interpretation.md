# Interpretation

## Overview

Interpretation describes what happened in your classroom economy during a **completed payroll cycle**. It is a report, not a live dashboard: each cycle is written once when the cycle closes and never changes afterward, so you can come back to an earlier cycle and see exactly what you saw before.

Interpretation deliberately does not score your class, rank students, or tell you what to do. It describes, and then asks questions.

## Step-by-step instructions

### Opening Interpretation

1. In the teacher sidebar, open **Economy**.
2. Select **Interpretation**.

The page opens on the most recently completed cycle.

### Choosing a cycle

If your class has more than one completed cycle, a **Cycle** selector appears near the top.

1. Pick a cycle from the list. Cycles are labeled by the date they were completed.
2. Select **View cycle**.

The page reloads showing that cycle. The report for a past cycle is frozen — it reflects the class as it was when that cycle closed, not as it is today.

### Moving around the report

Two navigation aids sit above the report body:

- The **overview cards** near the top list every section in this cycle's report. Selecting a card jumps to that section.
- **Jump to a section** is a dropdown with a **Go** button that does the same thing, which is easier on a phone or with a keyboard.

## What is in a report

A report is made of sections. Each section has a short summary, an optional **How to read this** note explaining what the section does and does not mean, and a list of observations.

Sections only appear when the cycle produced something for them, so two cycles will not always have the same sections.

| Section | What it covers |
| --- | --- |
| How students participated | Attendance recorded during the cycle — the activity that earns pay |
| How students used the economy | Actions students started themselves: spending, transfers, purchases |
| What happened with obligations | How debts such as rent were settled: paid, waived, or left unpaid |
| Savings | Whether students held savings and whether they added to them this cycle |
| Where income came from | The mix of income sources — earned work, awards, refunds |
| Money at the end of the cycle | Balances remaining when the cycle closed, including how many students ended at or below zero |
| Additional observations | Independent signals reported on their own, which do not roll up into a score |

### Reading an observation

Each observation shows a headline value, sometimes with supporting detail underneath, and a plain-language summary of what it describes.

An observation may instead read **Not applicable this cycle**, with a short reason. That is a normal outcome. It usually means the underlying activity did not happen — for example, no obligations came due — rather than that something went wrong.

### Questions to consider

Most observations, and each section, end with a collapsed **Questions to consider** disclosure. These are open prompts for your own reflection. They are collapsed on purpose so they never read as conclusions about the numbers above them.

Interpretation has no view into why your class did what it did. You do. The questions are there to connect the description to context only you have.

## Before your first cycle

A new class shows **No completed interpretation yet**, with a note that interpretation will appear after the first payroll cycle is completed.

Nothing is broken. Interpretation is written from completed cycles only, so there is nothing to report until you have run and completed a payroll cycle. See [Payroll Settings](payroll-settings.md) for how cycles are configured and completed.

## Important notes

> [!NOTE]
> **Interpretation is per class.** The report always covers the class currently selected in the top navigation bar. Switch classes there to see another class's report.

> [!TIP]
> **Compare cycles, not students.** The most useful reading is one cycle against another for the same class. Interpretation is built to describe patterns over time, not to rank individuals.
