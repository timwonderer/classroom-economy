# Switch Classes

## Overview

If you belong to more than one classroom economy, everything you see — money, store, pay, bills — belongs to whichever class is currently selected. Switching is how you move between them without signing out.

If you only belong to one class, the selector does not appear at all. Nothing is missing.

## Step-by-step instructions

### Switching

1. Scroll to the **bottom** of the sidebar, just above **Sign Out**.
2. Find **Switch Class** and open the drop-down beneath it. Each entry reads like *Period 3 with Ms. Rivera*.
3. Pick a class. The page reloads into it.

If the switch fails, a yellow message appears directly under the selector explaining why. Nothing changes until the reload succeeds.

### Confirming which class you are in

The top of the sidebar always shows your name, the class name, and that class's join code. Check there after switching if you are unsure.

### Adding a class you are not in yet

The **+** beside the **Switch Class** label opens the add-class page. The selector only lists classes you already belong to — it will never show a class you have not joined.

## What follows the class you pick

Everything class-specific:

- Checking and savings balances, and all transaction history
- The store and anything you have bought
- **Work & Pay** — attendance, hours, and paychecks
- **Bills** — rent and insurance
- Which features exist at all: a class with no store has no **Store** link in the sidebar

## Important notes

> [!IMPORTANT]
> **Money does not travel between classes.** Each class keeps its own separate balances. Being rich in one class does not help you in another.

> [!NOTE]
> **Missing a class?** If a class you expect is not in the list, you have not joined it yet. Use the **+** and your teacher's join code.

> [!TIP]
> The sidebar menu itself changes between classes, because teachers turn different features on. If a link you used yesterday is gone, check which class you are in before assuming something broke.
