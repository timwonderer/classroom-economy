Use this page to solve common classroom setup and support issues quickly.

Common tasks:

- check class setup and student seats
- review payroll, store items, rent, insurance, and hall passes
- submit a support ticket with the right class selected
- find the right help page without leaving the app

If something is wrong:

- confirm you are in the correct class
- read the page-specific help drawer first
- open the support page and include the class, page, and what you expected
