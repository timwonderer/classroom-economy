# Attendance and Payroll

Use this page when you are ready to pay students.

## Before you run payroll

- Confirm the correct class is selected.
- Check attendance records.
- Review the active pay rules.

## After you run payroll

- Review the results.
- Look for a missing record or a class mismatch if the numbers seem wrong.
