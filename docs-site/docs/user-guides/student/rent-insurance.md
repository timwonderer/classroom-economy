# Rent and Insurance

Use this page when rent or insurance needs attention.

## Rent

- Check the due date.
- Make sure you are in the correct class.
- Ask your teacher if the amount looks wrong.

## Insurance

- Check what coverage your teacher offers.
- File a claim if the event is covered.
- Wait for the teacher to review the claim.
