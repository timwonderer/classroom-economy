# Help and Issue Reports

Use this page when something does not work the way you expect.

## Start here

- Check the page you are on.
- Make sure the correct class is selected.
- Read the message shown on the screen.

## If you still need help

- Open Help and Support.
- Describe what happened.
- Include the class and the thing that went wrong.
