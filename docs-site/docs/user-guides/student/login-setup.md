# Sign In and Set Up

Use this page if you cannot get into your account.

## What to check

- Use the correct class.
- Enter the information exactly as your teacher gave it to you.
- Make sure the page finished loading before you try again.

## If it still does not work

- Ask your teacher to check the class you are trying to join.
- Ask your teacher to help you with your account if you are already in the class but cannot sign in.
