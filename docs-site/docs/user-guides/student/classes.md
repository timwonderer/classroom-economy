# Join or Switch Classes

Use this page when you need the right class open.

## Join a class

- Use the class code your teacher gave you.
- Make sure you are joining the correct class.
- Finish the join step before moving on to other tasks.

## Switch classes

- Open the class switcher.
- Pick the class you want.
- Check the page title or class name before you start work.
