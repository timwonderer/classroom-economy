# Attendance and Pay

Use this page when your attendance or pay looks wrong.

## What to check

- Are you in the correct class?
- Were you present during the class period?
- Does the page show the pay or attendance you expected?

## If the result looks wrong

- Refresh the page once.
- Check the current class first.
- Ask your teacher to review the record if it still looks wrong.
