Use this page to solve the most common student issues quickly.

Common tasks:

- sign in and get into the right class
- switch classes when you are in the wrong one
- check your balance, store, rent, and insurance
- report a problem with a transaction, attendance, or hall pass

If something is not working:

- confirm the correct class is selected
- read the message shown on the page
- use the Help and Support page to send a report if the issue still looks wrong
